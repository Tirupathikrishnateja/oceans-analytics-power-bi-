# Oceans Analytics Dashboard | Power BI

## 📌 Project Overview

This project presents an ocean-related data visualization dashboard developed using Microsoft Power BI.

The objective is to organize and visualize the ocean-related information available in the project dataset, making it easier to explore patterns, compare categories, and communicate findings through interactive reports.

The project demonstrates practical business intelligence and data visualization skills, including dashboard design, structured data exploration, and analytical reporting.
